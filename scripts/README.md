# 牛客比赛成绩更新脚本

## 功能介绍

这个Python脚本用于自动更新牛客比赛成绩到CSV文件中。它通过调用本地npm服务的API获取比赛榜单数据，然后匹配CSV中的用户并更新成绩。

## 使用场景

适用于需要批量更新比赛成绩到Excel/CSV文件的场景，特别适合算法竞赛集训营等需要记录多场比赛成绩的情况。

## 安装依赖

```bash
cd scripts
pip install -r requirements.txt
```

或者直接安装：

```bash
pip install requests
```

## 使用步骤

### 1. 启动npm服务

首先确保爬虫服务已启动：

```bash
# 在项目根目录
npm start
```

服务启动后，会监听 `http://localhost:8080`

### 2. 运行脚本

```bash
python scripts/update_contest_scores.py
```

或者：

```bash
cd scripts
python update_contest_scores.py
```

### 3. 输入比赛ID

```
请输入比赛ID: 124960
```

### 4. 确认保存

脚本会显示匹配结果，确认后输入 `y` 保存：

```
是否保存到CSV文件? (y/n): y
```

## CSV文件要求

脚本期望的CSV文件结构：

| 列名 | 必需 | 说明 |
|------|------|------|
| 姓名 | ✓ | 用户姓名 |
| 学号 | ✓ | 用户学号 |
| 牛客ID | ✓ | 牛客用户ID（优先匹配） |
| 牛客账号名 | ✓ | 牛客用户名（备用匹配） |
| 第N场成绩 | - | 成绩列，自动追加 |

## 成绩格式

- **格式**: `{过题数}({罚时})`
- **示例**: `6(254)` 表示6题，罚时254分钟
- **罚时计算**: `round(timeCost / 60)`，timeCost由API返回（单位：秒）

## 用户匹配策略

1. **优先匹配**: 使用牛客ID进行精确匹配
2. **备用匹配**: 如果ID匹配失败，使用牛客账号名匹配
3. **未匹配**: 榜单中有但CSV中找不到的用户会在最后列出

## 列追加逻辑

- 脚本会自动找到第一个空的成绩列
- 如果所有成绩列都已填满，会自动追加新列
- 列名格式：`第N场成绩`（N为场次编号）

## 错误处理

### 常见错误及解决方法

**错误: 连接失败: 无法连接到 http://localhost:8080**
- 检查npm服务是否已启动
- 运行 `npm start` 启动服务

**错误: CSV文件不存在**
- 检查CSV文件路径是否正确
- 确保文件在项目根目录

**错误: 没有写入权限**
- 关闭Excel或其他打开CSV的程序
- 确保文件没有被占用

## 注意事项

1. **备份**: 脚本会在保存前自动创建 `.bak` 备份文件
2. **编码**: CSV文件使用 UTF-8 编码（带BOM）
3. **确认**: 修改前会要求确认，避免误操作
4. **服务**: 确保npm服务在脚本运行期间保持启动
